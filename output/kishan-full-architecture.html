06 · Live updates · separate socket host

Socket.IO

Persistent Node server (server.js) → order / quotation / shipment events → Socket.IO client (VITE_SOCKET_URL) → TanStack Query invalidation → refreshed frontend

Optional in production. The Vercel Express entry point does not start Socket.IO. Event-producing API operations must reach the socket-enabled runtime for this connection to work.
